# Sprite generation

Created using the built-in imagegen tool. Source atlas PNGs are preserved here. `tools/dogs/convert_sprites.py` crops, scales with nearest-neighbor sampling, applies hard alpha, and quantizes to the four DMG shades. The result is draft game-ready pixel art, to be refined after playtesting.

## Starter atlas

Production Game Boy starter sprite atlas on transparent background: exact six columns by three rows with generous margins, no text or grid lines. Row 1 Groenendael sheepdog, row 2 Shiba Inu, row 3 Newfoundland. Columns: puppy front, puppy back, adolescent front, adolescent back, adult front, adult back. Crisp four-shade grayscale pixel art, readable at 56x56 front and 32x32 back. Groenendael long black fur, upright ears and grass-leaf ruff; Shiba curled flame tail and compact foxlike face; Newfoundland bulky shaggy floppy-eared with water-wave coat accents. Quadrupedal dogs, each centered in its own cell, no overlap, no props or scenery.
